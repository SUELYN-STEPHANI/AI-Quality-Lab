# Objective

Evaluate how prompt design influences the quality of AI-generated responses.

This study compares three prompts with different levels of specificity while requesting the same task. The objective is to demonstrate how prompt engineering directly affects response quality, completeness and instruction adherence.

---

# Task

Create a one-day travel itinerary for Paris.

---

# Prompt A

Create a travel itinerary for Paris.

---

# Prompt B

Create a one-day travel itinerary for Paris including morning, afternoon and evening activities.

---

# Prompt C

Create a one-day travel itinerary for a first-time visitor to Paris with a limited budget. Include morning, afternoon and evening activities, estimated costs, transportation suggestions and local food recommendations.

---

# Evaluation Framework

The prompts were evaluated using the AI Quality Lab Evaluation Framework v1.0.

Evaluation Criteria:

- Clarity
- Context
- Specificity
- Constraint Definition
- Expected Output
- Instruction Quality
- Reproducibility
- Response Consistency
- Overall Effectiveness

# Analysis

Prompt A is intentionally generic. Although it generates a usable response, it leaves many decisions to the model, producing inconsistent results.

Prompt B improves response quality by defining the desired structure, making outputs more organized and predictable.

Prompt C provides context, constraints and clear expectations. As a result, the responses become significantly more complete, consistent and aligned with the user's objective.

The comparison demonstrates that prompt quality has a direct impact on response quality.

---

# Conclusion

Prompt engineering is not simply about asking better questions; it is about reducing ambiguity and improving reproducibility.

Well-structured prompts consistently generate responses that are more accurate, complete and useful.

This study demonstrates the importance of prompt evaluation as a core competency in AI Quality.
